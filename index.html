Sobre o Portal Geek

O Portal Geek é um projeto desenvolvido para centralizar notícias, análises e curiosidades sobre a cultura pop, incluindo animes, cinema, séries e o universo dos quadrinhos.

Tecnologias Utilizadas

  • HTML5: Estruturação semântica e acessível.
  • CSS3: Estilização moderna, Grid Layout, Flexbox e design responsivo.
  • JavaScript (ES6+): Manipulação dinâmica do DOM, filtros de busca, categorização e renderização modular de dados.
  • Git & GitHub: Controle de versão e hospedagem do código fonte.

Objetivo do Projeto

Demonstrar a aplicação prática de conceitos fundamentais de desenvolvimento Web Front-End na criação de interfaces dinâmicas, limpas e interativas.
