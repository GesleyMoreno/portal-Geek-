Sobre o Projeto

O GeekPortal é uma aplicação web interativa focada no universo da cultura pop, animes, filmes e séries. O projeto foi idealizado e totalmente desenvolvido por Gesley Moreno da Silva como parte do seu portfólio de desenvolvimento web.

🎯 Objetivos & Funcionalidades

  • Interface moderna, responsiva e focada na experiência do utilizador (UX/UI).
  • Filtros dinâmicos por categorias e navegação por abas em tempo real.
  • Sistema de busca por palavras-chave no título e descrição dos artigos.
  • Leitura completa de matérias através de janelas modais interativas.

🛠️ Tecnologias Utilizadas

• HTML5: Estruturação semântica da página.
• CSS3: Estilização moderna, layout flexível e design responsivo.
• JavaScript (ES6+): Manipulação dinâmica do DOM, filtragem de dados e eventos.
• Git & GitHub: Controle de versão e alojamento via GitHub Pages.
